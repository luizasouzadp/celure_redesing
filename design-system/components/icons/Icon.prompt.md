Renders a bundled icon by name — the source's own SVG set plus the Celure "e" mark; never substitute an icon library.
```jsx
<Icon name="pin" size=".875rem" />
<Icon name="step-1" size="3.0625rem" />
<Icon name="celure-mark" size="1.25rem" />
```
- Property icons (pin, calendar, users, location, earth, yoga) render at .875rem
- `stars` is a 5-star rating strip: width 3.3125rem, height .5625rem
- step-1…4 are 49px line illustrations for "Como funciona"
